// ============================================
// PRO TIPS

/*
1. USE THE 8PX SYSTEM
   - Everything is a multiple of 8px (4px, 8px, 16px, 24px, 32px...)
   - Creates visual harmony and consistency

2. NAMING CONVENTIONS
   - xs, sm, md, lg, xl, 2xl, 3xl... (t-shirt sizing)
   - Easy to understand and remember
   - Consistent across all scales

3. DON'T MIX UNITS
   - Use rem for fonts and spacing (scales with user preferences)
   - Use px for borders and tiny measurements
   - Use % or vw/vh for full-width elements

4. START SIMPLE
   - You don't need ALL of these immediately
   - Start with: spacing, font sizes, colors, and shadows
   - Add more as your project grows

5. BE CONSISTENT
   - Pick values from your scale, don't create random sizes
   - If you need 23px and you have 24px available, use 24px
   - This creates visual consistency automatically
*/

The 8px Rule:
Everything should be a multiple of 8px (8, 16, 24, 32, 40, 48...). This creates visual harmony automatically!
When in doubt:

Small elements → use sm
Normal elements → use md (your default)
Big elements → use lg or xl
